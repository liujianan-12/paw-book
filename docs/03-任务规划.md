# 03 任务规划

> 每项任务标注：依赖（必须先完成的前置任务）、覆盖的需求编号（R*/I*/S*，见 01-需求说明.md）、完成条件（DoD）。
> 顺序即建议实施顺序；完成条件不满足不得进入依赖它的后续任务。

## T0 项目骨架与约束准备
- 内容：go mod 初始化；目录结构（cmd / internal / web）；SQLite 初始化与建表脚本；教学时钟（可配置的 2 小时/5 分钟规则）；AGENTS.md；Git 分支规范确认。
- 依赖：无
- 覆盖：7.技术边界
- DoD：`go build ./...` 通过；空库可初始化；时钟参数可从配置读取。

## T1 数据模型与迁移
- 内容：建表——门店、员工、用户、宠物、服务项目、时段、预约、支付单、退款单、取消审核单、支付异常、审计日志。状态字段全部用字符串常量（与状态机一一对应）。
- 依赖：T0
- 覆盖：第 5 节状态机
- DoD：迁移脚本可重复执行；字段与状态机状态一一对应并有常量定义。

## T2 模拟支付渠道服务
- 内容：独立小 HTTP 服务，支持注入行为：成功 / 失败 / 超时 / 重复回调通知；提供支付回调与退款结果回调。
- 依赖：T0
- 覆盖：R7、R8、R9、A6
- DoD：四种行为均可通过参数触发并复现。

## T3 时段与名额（含并发抢位）
- 内容：店长创建时段；可约列表查询；有效名额计算（R2 的"有效"口径）；并发预约抢位控制（事务 + 数据库约束，保证不超卖）。
- 依赖：T1
- 覆盖：R1–R5、I1、I2、S2
- DoD：并发 50 请求抢 3 个名额，成功数恰为 3（-race 测试通过）。

## T4 预约创建
- 内容：选宠物创建预约；校验宠物归属（防越权改 ID）、同宠物同时段唯一、名额、时段未开始；未付款预约记录 5 分钟占位截止时间。
- 依赖：T3
- 覆盖：R2–R4、越权校验、S2
- DoD：非法输入均有明确错误码与提示；越权请求被拒绝。

## T5 支付与支付异常
- 内容：发起支付 → 模拟渠道回调；回调幂等（重复通知不重复确认）；已关闭预约收到支付成功 → 登记支付异常 + 自动退款（复用退款模块入口，T7 完成后联动）。
- 依赖：T2、T4
- 覆盖：R6–R9、I3、A4、A6
- DoD：重复回调只确认一次；关闭后回调生成异常记录且发起退款；渠道失败时预约不前进。

## T6 超时取消（名额释放）
- 内容：待支付超过 5 分钟自动取消并释放名额（定时扫描 + 读取时懒检查双保险）；释放仅一次（幂等）。
- 依赖：T4
- 覆盖：R4、R13、I4、S2
- DoD：教学时钟调短后可演示超时释放；并发下名额不重复释放、不超卖。

## T7 取消与审核
- 内容：≥2 小时自动受理；<2 小时须填原因进入取消审核中（名额保留、禁止核销）；客服批准/拒绝；拒绝恢复已确认。
- 依赖：T4
- 覆盖：R10–R13、A2、S3
- DoD：两条分支结果正确；审核期间核销被拒绝；名额只在终态释放一次。

## T8 退款
- 内容：独立退款单；状态：待退款/退款中/成功/失败；失败可由客服重试；退款不影响预约终态；金额勾稽可查。
- 依赖：T2（渠道）、T7
- 覆盖：R14、A3、A4、S3
- DoD：注入渠道失败后可重试成功；取消状态不被退款改变；退款记录独立可查。

## T9 核销与履约
- 内容：前台核销（三条件校验：本店+已确认+无待审核取消）；与取消并发的唯一合法结果（行锁/条件更新）；服务开始、完成登记；重复核销/完成幂等；非本店员工拒绝。
- 依赖：T4、T7
- 覆盖：R15–R20、I4、I5、S1、S4
- DoD：核销与取消并发测试恰有一个成功；重复核销只记一次收入；越权员工被拒。

## T10 未到店标记
- 内容：时段结束后，店长可将已确认预约标记未到店（必填原因，终态不可逆）；不自动退款；用户可查看。
- 依赖：T9
- 覆盖：R21、R22、A5
- DoD：标记后状态与原因持久化；已核销/已完成不可再标记。

## T11 店长日清
- 内容：当日各时段统计（有效/已完成/取消/未到店/退款待处理）；金额勾稽：已收款 = 已完成收入 + 已退款 + 未退款。
- 依赖：T5、T7–T10
- 覆盖：R23、R24、I3、S5
- DoD：构造含四种记录的一天，勾稽等式成立并可在页面核对。

## T12 页面与会话
- 内容：四角色页面接真实数据（以原型为蓝本）；预置账号登录会话；所有写操作走会话身份，不信任请求参数中的用户 ID。
- 依赖：T3–T11
- 覆盖：7.技术边界、S1–S5
- DoD：S1–S5 全部可在页面实际操作完成；修改请求中的用户 ID 无法越权。

## T13 测试与覆盖率
- 内容：状态机不变量 I1–I6 单元测试；并发用例（抢位、核销 vs 取消、重复回调）带 -race；核心业务包覆盖率 ≥85%；集成测试（真实 SQLite）。
- 依赖：T3–T12
- 覆盖：第一部分第 6 节全部要求
- DoD：`go test ./... -race -coverprofile` 通过且各核心包 ≥85%，原始输出存档。

## T14 流水线与部署
- 内容：CI（格式检查、go vet、测试+覆盖率门禁、构建）、部署到教学验收环境、健康检查、业务冒烟检查（预置数据→预约→支付→核销一条链）、回滚说明。
- 依赖：T13
- 覆盖：第一部分第 7 节
- DoD：一次真实部署记录：运行地址、流水线运行标识、版本、冒烟结果。

```
                    │            ↓
                    └────────→ T11 → T12 → T13 → T14
```
