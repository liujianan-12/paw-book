# T02-T08 开发：核销与服务履约（R5/R6）

- 规则：R5.1–R5.3、R6.1–R6.2、D6、I8、A9/A10/A11
- 状态：开发完成（2026-11-12）
- depends: T02-T07

## 变更

1. `checkin.go`
   - `CheckIn`：本店前台（P3/P4）+ 已确认 + 无待审取消（状态与 `cancel_request` 双校验）+ 条件更新；成功写唯一 `checkin_record`。
   - `StartService`：本店服务人员、已到店 → 服务中，写 `service_record.started_*`。
   - `CompleteService`：服务中 → 已完成，写 `service_record.completed_*`；完成即唯一收入确认。
   - 幂等：重复核销/开始/完成返回 `alreadyDone=true`，不新增记录、不重复记收入（D6/R5.3），仍校验角色与门店。
2. 条件更新以 `RowsAffected` 判定；败者返回 `RESERVATION_STATE_INVALID` 或明确状态码（R6.1）。

## 测试

- `checkin_test.go`：未付款/已取消/待审/跨店/错角色核销拒绝；同员工、不同员工重复核销与完成；`checkin_record`/`service_record` 各 1 条；越级开始/完成拒绝；R7 未到店。
- `failure_test.go`：预约更新失败/名额更新失败返回错误并回滚；`RAISE(IGNORE)` 模拟条件更新败者。
