# T02-T06 开发：预约与支付（R1/R2）

- 规则：R1.1–R1.4、R2.1–R2.7、I1/I3/I13、A3/A4/A5
- 状态：开发完成（2026-11-12）
- depends: T02-T05

## 变更

1. `slot.go`：`CreateSlot` 增加店长角色 + 本店校验（P3/P4）；容量 1–3、未来时段（R1.1）。
2. `reservation.go`：
   - 宠物归属校验（P1），条件自增名额 `reserved_count<capacity AND start_at>now`（R1.3/R1.4）。
   - 唯一索引冲突统一映射 `DUPLICATE_ACTIVE_RESERVATION`（R1.2，SQLite 报错不含索引名，按表+列识别）。
   - 未付款取消释放名额、无退款（R2.3）。
3. `pay.go`：
   - 每次发起支付生成新 `payment` 流水 + 新 `order_no` + `attempt`（R2.7）。
   - 回调按 `channel_txn_id` 幂等；重复成功/失败均不改状态（R2.5）。
   - 预约已关闭（取消/过期）收到成功回调 → `payment_anomaly` + `refund(LATE_PAYMENT)`，预约状态不变（R2.6/I10）。
   - 成功后其余 INIT 流水标记 FAILED，保证同预约仅一条 SUCCESS（I13）。
4. `sweep.go`：过期扫描改为事务内可复用（`expireSlotTx`/`expireReservationTx`），条件更新 + `seat_released` 保证只释放一次（R2.2/I5）。
