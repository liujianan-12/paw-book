# T02-T07 开发：取消与退款（R3/R4）

- 规则：R3.1–R3.3、R4.1–R4.4、D3/D4/D6、I6/I8、A6/A12/A13/A14/A15/A16
- 状态：开发完成（2026-11-12）
- depends: T02-T06

## 变更

1. `cancel.go`
   - `CancelReservation`：`start-now >= 2h` 自动受理（取消 + 释放名额 + 全额退款）；`<2h` 必填原因并插入 `cancel_request(PENDING)`，预约为 `CANCELLATION_REVIEW`，名额保持（R3.1/R3.2）。
   - 待审中重复提交返回 `CANCEL_ALREADY_PENDING`；被拒后可再次提交，历史保留（D3/A6）。
   - `ReviewCancel`：仅本店客服、仅 PENDING；批准 → 取消 + 释放名额一次 + 退款；拒绝 → 恢复 `CONFIRMED`、名额不变（R3.3/R4.1/R4.2）。
   - `refundOfReservation`：仅对存在成功支付的预约创建退款，统一走 `ensureRefund`（A4/I4）。
2. `refund.go`
   - `ensureRefund`：一预约一退款（I8），已存在则复用。
   - `HandleRefundNotify`：只改退款单状态，失败不改变预约（I6/R4.4）；重复成功幂等。
   - `RetryRefund`：仅本店客服；仅 `FAILED/PENDING` 可重试，`retry_count+1`（D4 口径：客服主动重试次数）。
   - `ListRefunds`：本店 + 未完成过滤（A15）。
