# 11 验收清单（逐项对照题面，验收 Agent 只认证据）

用法：Acceptance Agent 按本表逐项填写 `docs/acceptance/acceptance-report-<sha>.md`；结论只能是 **PASS / FAIL / BLOCKED**，FAIL/BLOCKED 必须写缺什么；缺证据一律 FAIL，不得凭开发声明通过。学生最后按本表复查一遍。

## 8. 结论规则

- 全部 PASS → 验收通过；任何 FAIL → 回开发分支修复并重新走门禁与部署，**不得直接改 main**。
- BLOCKED（如教师未提供 MCP/meegle/部署环境）必须写清阻塞点、已尝试记录与替代证据；不得用“环境问题”掩盖未实现。meegle 不可用按 `docs/assumptions.md` D4 记 BLOCKED：该提交不计合规但不判造假，教师环境就绪后补核验。
- 验收 Agent 的结论必须逐项指向文件/命令/截图索引；教师独立验收为最终依据。
